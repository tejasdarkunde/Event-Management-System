# Event-Management-System
📌 Overview

This is a Spring Boot-based Event Management System that helps users book and manage events with ease. The system includes features for handling users, events, bookings, catering, and payments.

🚀 Features

🏢 Admin Panel - Manage users, events, hotel, catering and bookings.

🎊 Event Booking - Users can book different types of events.

🍽️ Catering Management - Organize food services for events.

🏨 Hotel Management - Organize hotel services for events.

💳 Payment System - Secure and easy payment processing.

📄 PDF Export - Generate and download reports in PDF format.

🛠️ Technologies Used

Backend: Spring Boot, Java

Frontend: jsp

Database: MySQL

Build Tool: Maven
